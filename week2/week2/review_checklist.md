# The three comments

Leave exactly three, one of each kind. Write them as questions where you can.

1. **Correctness.** One case the code gets wrong, or one you cannot tell either
   way. Name the input.
2. **Naming.** One name that does not say what the thing is. Suggest the
   replacement rather than only objecting.
3. **A test that is missing.** Name the input and the expected output, not the
   idea of a test.

Read the whole file before you write any of them.
